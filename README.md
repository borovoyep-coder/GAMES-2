# Долина осколков — Blender / Unity 0.6

Частный 3D-просмотр 41 набора из Unity-проекта: карта, миньоны, монстры, строения, 100 клипов, кристальные проходы, автоматическая смена мостов, каскады и исходники для скачивания. Три уровня графики. Рендеры Blender обозначены отдельно.

Симуляция локального матча находится в скачиваемом Unity-проекте. На сайте показан осмотр сцены. CPU-проверки геометрии/ключей и локальных ссылок выполнены; управляемый браузер отсутствует, WebGL/FPS здесь не проверялись.

Размещение сохраняет существующий доступ владельца. dist — buildless HTML/ES modules, внешние CDN не требуются. Архивы загружаются по SHA-256-проверяемым частям с отдельной страницы download.html.
