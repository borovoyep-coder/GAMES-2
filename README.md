# Долина осколков — Blender / Unity Art 0.4

Главный адрес открывает 3D-просмотр тех же 34 наборов геометрии и текстур, что и Unity-проект. Башни размещаются из 18 явных TowerSlot; можно подсветить боковые проходы и внешний обход. Вода и 42 Blender-модели пены движутся по изогнутому руслу. Мосты ориентированы по нормали к реке.

`dist/unity-map` содержит Three.js, сжатые меши, изображения и инструменты осмотра. Доступны карта, существа, рендеры Blender и архив Unity с `.blend`, 33 FBX, разметкой и исходниками генераторов. Это просмотр моделей, а не Unity WebGL-сборка. Unity Editor отсутствует; импорт и URP требуют проверки в Unity.

Проверяются синтаксис просмотрщика, локальные ссылки и UI-связи, бинарные потоки всех моделей и количество треугольников. Browser QA не проводилась: управляемый browser helper недоступен. Реальный WebGL, ввод и FPS требуют проверки в браузере и на устройстве. Аудитория существующего сайта сохранена.

Прежний браузерный боевой прототип сохранён в `dist/battle.html`; его симуляция не заменяет Unity-проект.
