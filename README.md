# Долина Осколков — схема 200.5

Текущая сцена `/valley-200/` перестроена по нормализованным X/Z координатам последнего задания. Базы (−80,+80)/(+80,−80); точные 18 башен, 12 лагерей, шесть кристальных преград и 26 кустов. Top при повороте на 180° переходит в Bot, Mid — в себя. Дорожки, островки, коллизии и внешние скалы строятся симметричными парами.

В `stealth.mjs` добавлены `StealthBush` и общая логика видимости для героев, миньонов и башен. `stealth-view.mjs` управляет отдельными материалами: союзная opacity 0.45, вражеская модель и метки скрыты. Урон/умение раскрывает на две секунды, враги в одном кусте видят друг друга. Есть переключение обзора команд для локальной проверки.

Согласованные точки (−32,−18)/(+18,+32) — входы с синего берега; центры мостов (−25,−25)/(+25,+25). Четыре периметральных коллайдера и ограничение навигации исключают выход за поле боя. Рабочие волны, нейтралы, фонтаны, мосты и затворы сохранены.

Проверяются независимые координаты, каждая ячейка симметричной маски, повёрнутые A* маршруты, все шесть сокращений пути и реальный выбор целей при скрытии. Также выполнены Blender read-back, регрессии боёв/анимаций и проверки потоков геометрии. WebGL, реальные касания, Unity и FPS в среде не запускались.

Архив редактируемой Blender-сцены, кода, схемы и логов доступен на странице карты. Подробности: `dist/valley-200/README.md`, `TEST_REPORT.md`. Это локальная симуляция Three.js; старый Unity-прототип сохранён отдельно по `/unity-map/`. Доступ к сайту остаётся владельческим.
