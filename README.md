# Долина Осколков — лабиринт 200.7

Текущая карта `/valley-200/`: узкие S-образные тропы 1.8 единицы, закрытые руинами 4 поляны и 12 лагерей, сплошные объёмные основания рощ, плотные тёмные ели и 40 групп высокой травы. Между линиями и внешними горными тропами добавлены препятствия и засады. Мидовые кристаллы находятся в (-10,+32)/(+10,-32); остальные четыре сохранены.

Навигация запекается из тех же поверхностей, что задают геометрию. Все 667 489 ячеек имеют поворотную пару. Точки вне троп, карманов, полян, кустов, линий, баз и арен непроходимы. Плоская физика Y=0 сохранена.

Браузерные проверки из корня репозитория: `node tests-valley-200.mjs`, `node tests-gameplay.mjs`, `node tests-combat.mjs`, `node tests-combat-view.mjs`, `node tests-symmetry.mjs`, `node tests-stealth.mjs`, `node tests-forest.mjs`.

Сцена Blender, три модуля генератора, исходники и отчёт доступны в ZIP. Предыдущий `/unity-map/` сохранён. Реальные ограничения проверки приведены в `dist/valley-200/TEST_REPORT.md`.
