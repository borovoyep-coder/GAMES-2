# Долина осколков — браузерная демоверсия

Отдельная браузерная реализация игрового каркаса. Это не WebGL-сборка Unity: исходный Unity-проект сохранён без изменений и доступен для скачивания из меню.

`dist/engine.mjs` — локальная симуляция; `app.mjs` — Three.js, управление и UI. `assets/map.json` экспортирован из Unity MapLayout. Three.js 0.170.0 загружается локально, без CDN во время игры. Состояние матчей хранится в памяти вкладки; серверного мультиплеера нет.

Управление: WASD / ПКМ, удерживать Пробел, Q/E/R в сторону курсора, B — база, I — магазин, Tab — карта, F — портал, Esc — пауза. На сенсорном устройстве доступны джойстик и кнопки; способности автоматически выбирают ближайшую цель. В тренировке есть ускорение и переход на две минуты вперёд.

Проверка: `node tests.mjs --smoke`. Это независимые проверки JS-логики и 180 игровых секунд симуляции. Браузерная QA в текущей управляемой среде недоступна: отсутствует инструмент `cua_repl.js`. Проверка WebGL, реального сенсорного ввода и FPS не проводилась. Длительность и баланс матча предварительные.

Исходные требования и ограничения Unity-версии находятся в скачиваемом архиве. У браузерной версии упрощены особые лесные способности, модификаторы, графика и поведение ботов.
