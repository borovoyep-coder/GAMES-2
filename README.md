# Долина осколков — просмотр Unity Art 0.3

Главный адрес открывает интерактивный 3D-просмотр новой карты и оригинальных монстров для Unity. Просмотр использует те же вершины, нормали, UV и текстуры, что и Unity-проект; отдельный бинарный формат нужен только для экономной передачи в браузер.

`dist/unity-map` содержит сцену Three.js, сжатые меши, изображения и инструменты осмотра мостов и кристаллов. В меню доступны карта, отдельная коллекция существ, рендеры Blender и скачивание всего Unity-проекта.

Это не Unity WebGL-сборка. Unity Editor здесь отсутствует; нативный проект включает автоматический генератор native Mesh/Material/Prefab assets и сцен осмотра и матча. Рендеры сделаны в Blender и подписаны соответствующим образом. Точность каждого камня по одной картинке не заявляется.

Предыдущий браузерный боевой прототип сохранён в `dist/battle.html`; его симуляция не заменяет Unity-проект. Проверка старого JS-слоя: `node tests.mjs --smoke`.

Проверены синтаксис нового просмотрщика, его локальные ссылки и UI-связи, все 27 бинарных наборов и совпадение числа треугольников с исходными моделями. Browser QA не проводилась: `cua_repl.js` в управляемой среде недоступен. Реальные WebGL, сенсорный ввод и FPS требуют проверки в браузере и на устройстве.
