# Долина осколков 0.7

3D-осмотр Blender-ассетов и детерминированный бой миньонов/башен с HP и снарядами. MatchRules экспортированы из Unity-проекта; Node-тесты проверяют бой на реальных координатах всех 18 башен и отсутствие пересечения тел. Локальный матч с героями находится в Unity-проекте. WebGL и Unity Editor здесь не запускались.
