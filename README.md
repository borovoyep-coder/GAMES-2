# Долина Осколков — карта 200×200

Корневая страница открывает `dist/valley-200/`: интерактивную сцену по новому заданию с 18 точными позициями башен, двумя базами, двумя боссами, 12 лагерями, четырьмя полянами, восемью разрушаемыми затворами, тремя каменными и двумя энергетическими мостами.

## Источник

Геометрия экспортирована из `ValleyOfShards.blend`, созданного автономным `generate_valley.py` в Blender 4.3.2. Исходный генератор, сцена, общий рендер, лицензия шрифта и интеграционные проверки доступны в `ValleyOfShards_Generator_Blender.zip` на странице карты. `scene.json` хранит SHA-256 исходного `.blend`, материалы, интерактивные объекты и анимационные данные. Сжатые потоки хранят позиции, нормали, UV, линейные цвета и ID владельцев треугольников.

Three.js применяет ту же геометрию и расположение. Процедурные материалы Blender адаптированы к цветам вершин и веб-шейдерам PBR: шейдерное изображение не заявляется пиксельно идентичным Cycles. Геометрия: 1 327 412 треугольников, включая экземпляры и тесселяцию кривых. Для сокращения числа draw calls она объединена в 348 мешей; динамические части выделены в 311 узлов.

## Интерактивность

- Вращение, масштаб, перемещение камеры; кнопки обзора, баз и арен.
- Выбор башен, лагерей, боссов, мостов и кристальных затворов. Карточки показывают исходные координаты.
- Кристаллы: шесть ударов по четыре единицы, разлёт осколков, подсветка открытого сокращения и автоматическое восстановление через 60 секунд; есть ручная кнопка восстановления.
- Течение и пена, брызги, круги водопадов, парение кристаллов и энергетических плит.
- Пресеты качества и мобильная навигация. Выбор Ultra не является подтверждением FPS на конкретном устройстве.

Это осмотр новой карты. Предыдущая сцена с симуляцией боя линий сохранена по `/unity-map/`; исходники локального матча Unity 0.9 доступны там же. Новая расстановка 200×200 не объявляется уже подключённой к симуляции Unity.

## Проверки

```bash
node --check dist/valley-200/viewer.mjs
node --check dist/valley-200/model.mjs
node tests-valley-200.mjs
```

Проверяются все заданные координаты, количества объектов, бинарные потоки и контрольные суммы, матрицы анимационных узлов, все восемь затворов, UI-привязки и локальные ссылки. В рабочей среде нет `cua_repl.js` и управляемого браузера: браузерный WebGL, визуальное отображение страницы, полный экран и реальные касания не запускались. Рендер `overview.jpg` получен из Blender, не из браузера.

Публикация через прежний Sites project_id с сохранением текущей аудитории. `.openai/hosting.json` не меняется.
