# Долина Осколков — обновление карты 200.3

Корневая страница открывает `dist/valley-200/`. Геометрия создана модульным Python-генератором Blender 4.0+, экспортирована из проверенной сцены Blender 4.3.2 и показана в Three.js. Архив исходников, `.blend`, четыре текстуры, документ дизайна и логи доступны на странице карты.

Обновление: плоская игровая физика Y=0 при декоративном каскадном окружении; широкая река под мостами и внешними аренами; отдельные лечебные фонтаны за Нексусами; 18 боковых троп от башен; по два постоянных входа к каждому боссу; восемь затворов по четыре роли на сторону.

`gameplay.mjs` содержит независимую от DOM симуляцию: `PlanarNavigation`, `PlanarWorld`, фиксированный шаг 30 Гц. Первый лесной мост открывается в 2:00; затем Рассвет и Сумерки чередуются каждые 120 секунд. За 15 секунд до закрытия есть предупреждение; герои плавно выталкиваются на ближайший берег без урона. Кристаллы имеют 24 прочности, получают 4 от ближней атаки или 3 от дальнего попадания, восстанавливаются через 60 секунд после освобождения прохода. Фонтаны лечат союзников и восстанавливают ману.

В локальном плейтесте присутствуют десять героев, один управляется пользователем, девять патрулируют. ПКМ по земле — движение, ЛКМ — выбор, F — герой. Кнопки позволяют проверить фонтан, оба типа атак по кристаллу, ускорение времени и безопасное закрытие моста. Это не сетевой матч и не полноценный боевой ИИ. Старый Unity-прототип сохранён отдельно по `/unity-map/`.

Материалы включают цветовые вариации, четыре собственные бесшовные карты деталей, парящие командные кристаллы и водные шейдеры с течением. Галерея содержит рендеры Blender, а не снимки браузерного отображения.

Проверки:

```bash
node --check dist/valley-200/viewer.mjs
node --check dist/valley-200/gameplay.mjs
node tests-valley-200.mjs
node tests-gameplay.mjs
```

Проверяются реальные бинарные меши, хеш исходного Blender-файла, 18 координат башен, проходимость постоянных маршрутов, таймеры, урон, лечение, восстановление и безопасное выталкивание. В среде нет поддерживаемого управляемого браузера и Unity Editor: WebGL, касания, APK, Unity и FPS не проверялись. Ultra — настройка качества, а не гарантия производительности.

Подробности — `dist/valley-200/README.md` и `TEST_REPORT.md`. Доступ опубликованного сайта сохраняется владельческим, без изменения аудитории.
