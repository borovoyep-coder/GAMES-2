# Долина Осколков — лесной проход 200.6

Текущая сцена `/valley-200/`: земляные тропы, пятнистые поляны, 240 тёмных елей, 38 барьеров из руин/скал, 40 капсульных зарослей высокой травы. Четыре горных участка соединены с 12 боковыми башнями. Перенесены только два средних кристалла, остальные четыре сохранены. Все изменения имеют партнёра при повороте на 180°; основной геймплей плоский Y=0.

Исходная сцена и модули поставляются в ZIP со страницы. Фактические меши экспортированы из Blender. Предыдущие `/unity-map/` и ранние загрузки сохранены.

Проверки: `node tests-valley-200.mjs`, `tests-gameplay.mjs`, `tests-combat.mjs`, `tests-combat-view.mjs`, `tests-symmetry.mjs`, `tests-stealth.mjs`, `tests-forest.mjs`. Запуск из корня репозитория. Дополнительные инструкции и фактические ограничения в `dist/valley-200/README.md` и `TEST_REPORT.md`.
