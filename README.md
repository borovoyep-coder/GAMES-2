# Живая долина — Blender / Unity 0.5

3D-просмотр тех же 38 наборов, локальных pivots и ключей анимации, что в Unity-проекте. Карта, монстры, миньоны и пять рендеров Blender; фонтаны позади нексусов, окружающий ландшафт, движущиеся реки/водопады, выход волн и графические пресеты.

Вкладка миньонов воспроизводит Idle/Walk/Attack/Death/Spawn из Blender. Просмотр волн демонстрирует выход, расписание и марш; бой и правила скрытия исполняются в Unity-проекте. Это не Unity WebGL-сборка.

Архивы Unity и Blender доступны через download.html; большой ZIP передаётся проверенными частями и собирается браузером в один файл. Каждый статический файл меньше 25 MiB. Сохранена прежняя приватная аудитория.

Проверены синтаксис, бинарные потоки/ключи, локальные ссылки, UI-связи и целостность скачиваемых архивов. Browser QA/WebGL/FPS не выполнены: управляемый browser helper недоступен. Старый 2D-прототип остаётся в battle.html.
